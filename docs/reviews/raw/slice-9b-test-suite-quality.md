### Strengths

- `internal/platform/resilience/resilience_test.go` is the model the rest of the suite should follow: a 12-case table for the 429-ignore predicate (Rule 12), then a real `httptest.Server` proving end-to-end that ten 429s leave the breaker closed while three 500s open it, with `reqCount` assertions proving the fourth request never reached the server. Real behavior, hardcoded literals, no mocking of internals.
- `internal/platform/cache/cache_test.go:17` proves singleflight suppression with genuine concurrency: ten goroutines, `computeCalls == 1`, still `1` on the L1 hit, then `2` after `Invalidate`. The call-count deltas are the actual behavioral contract, not an implementation mirror.
- `internal/platform/database/database_test.go:103` verifies savepoint nesting through observable business state read back over a *separate* admin connection — asserting on user names, not on sequence counters or row IDs, exactly as Rule 14 prescribes.
- `internal/platform/tenant/worker_test.go:23` is the strongest security test in the suite: it asserts the positive (tenant A scrubbed to exact literal values, blobs gone) *and* the negative (tenant B's user and blob byte-for-byte intact) across both the database and storage phases.
- `tests/testsuite/suite_test.go:22` verifies the auto-rollback harness from outside the transaction via the admin pool, and `TestRunTestInSchema_EphemeralIsolation` confirms the ephemeral schema is actually dropped after the callback. Both prove the harness rather than assuming it.

### Out-of-slice observations

- `internal/platform/app/coordinator.go:84` hardcodes `time.Sleep(100 * time.Millisecond)` with the comment "Short pause in tests, up to 2s in production" — the phase durations are not injectable, which is why the 25-second budget of Rule 13 cannot be asserted by any test.
- `tests/testsuite/suite.go:103` derives the `app_user` connection string via `strings.Replace(adminConnStr, "postgres:postgrespassword", "app_user:app_user_password", 1)`, silently yielding an admin (RLS-bypassing) pool if the container's credentials ever change — which would turn every RLS test green for the wrong reason.
- `tests/testsuite/suite.go` exports `SharedRedis` but only `suite_test.go` uses it; auth revocation, event idempotency, rate limiting, and notification enqueueing all pass `nil` instead, which is the root enabler of several findings above.
- `internal/platform/storage/storage.go` `DeletePrefix` and `Read` accept arbitrary caller-supplied keys with no tenant validation; the `TenantExtractor` hook is consulted only in `PresignedUpload`.
- `internal/modules/orders/service.go` `CancelOrder` discards the audit staging error with `_ = audit.StageAuditLog(...)`, so a compliance-log failure cannot fail the transaction — unlike `CreateOrder`, which propagates it.
- `cmd/clericot` (the module scaffolder CLI) and `cmd/worker` have no `_test.go` files at all; the scaffolder generates the 6-file module template downstream teams start from.
